# Vaibhav Bisht — Game Programmer & Engine Developer

I'm a game programmer specializing in **engine architecture**, **low-level systems**, and **real-time rendering**. Currently building REFlux — a custom C++ game engine — while studying Game Design & Development at ICAT, Bengaluru (graduating Mar 2026).

My focus is on the systems layer: memory management, rendering pipelines, and the architecture decisions that make games run well at scale.

---

## What I'm Building

**[REFlux Engine](https://vaibhavbisht.dev/ReFlux/)** — A custom C++ game engine built from scratch.
Modular layer stack · OpenGL 4.x backend · GLFW integration · Custom event dispatcher · spdlog logging · Custom math library (Vector2, Matrix4) · Input system

**[Low-Level Systems Library](https://github.com/vaibhavbisht-dev/Low-Level_Systems_Library)** — Core engine-level data structures without the STL.
- `DynamicArray` — Rule of Five, placement new, strong exception guarantee, amortized O(1) push_back
- `LinearArenaAllocator` — O(1) bump allocation, alignment-safe, marker system, debug memory poisoning
